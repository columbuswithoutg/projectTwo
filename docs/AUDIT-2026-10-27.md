## How to read this

Categories:

- **bug**: the code does the wrong thing in a reachable path.
- **dead-file**: a file that nothing references.
- **dead-code**: code, routes, exports, CSS selectors or dependencies that are never reached or used.
- **missing-test**: logic that matters but has no test, or tests that check a copy or an outdated layout.
- **risky-pattern**: works today but is fragile, slow, insecure or likely to break on a future change.

Likelihood is how likely the finding is to bite in real use, not how bad it is when it does. Confidence is how sure the auditor is that the finding is real.

### SRV-01: Username "heal" writes an empty usernameLower when called through Username.exists()

- **Where:** `server/username.js:93-101, 84-89, 106-108`; `routes/auth.js:33`

- **Confidence:** High
- **Rank:** 14 (Tier 2)

## How the fixes were run

The fixes ran in six waves plus a cleanup pass, with several fix agents per wave (about 35 in total). Waves 1 to 4 followed the original batch plan B1 to B4; wave 5 ran in two parallel halves (5a and 5b) over the B5+ list, and wave 6 took the remaining Tier 3 findings.

- Wave 1: world-socket join and zone (NET-02, RT-01/NET-01); sRGB textures (3D-01); walker lifecycle (MAP-01, 02, 03, 04, 06); Mongoose `returnDocument` (SRV-02); admin tab state and dirty guard (ADM-01, 02).
- Wave 2: content and asset fixes (TOOL-02, TOOL-09, MAP-09, MAP-10); PWA icons (TOOL-03); admin validation, runtime and reports (ADM-03, 04, 05); username heal (SRV-01); server boot hardening (RT-02/SRV-10, SRV-03, SRV-04, SRV-08, SRV-17, RT-03).
- Wave 3: auth and state hygiene (CLI-02, 03, 05); messages poll, house editor and composer blobs (CLI-01, NET-08, 09, CLI-04); chart camera, touch, XSS and layout cache (MAP-05, 11, 07, 08); voice (NET-03, 07); Scene Guess and socket client (NET-04, 05, 06, 10).
- Wave 4: 3D robustness (3D-02, 06, 07, 15, 16); dependencies and CI (TOOL-01, 05, 08, 12, SRV-21); seed safety, README and NUL byte (TOOL-06, 13, 15); user delete cascade (RT-05, 04, 09); build smoke test and collision check (TOOL-07, CLI-08).
- Wave 5a (parallel): physics constants shared and collision/ceiling/spawn extracted (3D-03, 08, 09, 13 plus two 3D loose ends); dead CSS removal and saving/error-cover rules (TOOL-14, ADM-18); remaining admin-panel bugs (ADM-07, 08, 10, 11, 12, 13 client side, plus the delete-user copy); test backfill (SRV-12, 3D-10, NET-17, RT-20, CLI-09).
- Wave 5b (parallel): route-level bugs, feed cursor and content caches (SRV-07, 11, 14, 15, 16, 18, 19, RT-11); admin sanitizer extraction and server-side admin fixes (RT-17, ADM-07, 09, 11 server side, MAP-14, RT-06, 07, 08, 10); feed merge and scene-data cache tests (RT-16, RT-18).
